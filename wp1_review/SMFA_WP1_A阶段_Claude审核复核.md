## 2. 最应采纳：补 C1，并按原规则重选 λ

c=0.75 到 1.0 的两个端点，相隔约 0.3035 遗忘 ROUGE、0.2221 保留图像 ROUGE。SMFA、B 目标、C2 λ10 和 C0 k10 都依赖这个区段的线性插值。未知曲率足以影响当前仅 0.01–0.02 的差距，因此补 c=0.8、0.85、0.9、0.95 合理，成本约两卡 2 小时，另计构造和调度。

在看到新增结果前，追加有日期及哈希的规则补充：仍按原 §6.1，使用原四点加新增四点，重新选 λ。原冻结记录、原 λ=10 及原报告保留，标记为旧曲线下的选择，不能覆盖成仿佛事先采用密集曲线。两折使用同一补点规则。

补完四点后仍要检查局部间距，均匀的 c 网格不保证遗忘 ROUGE 网格均匀。若 λ 排名改变，如实采用新选择；先前用于重估 h 的 C2 是按“最接近 SMFA”指定，不能为了得到更小 h 随 λ 选择随意换配对。

## 4. 机制解释需要收紧

硬投影、软收缩的结果支持：修改 S0 前 90% 能量子空间，会显著削弱目前 LoRA 的行为遗忘效果。它不直接证明“绝大部分遗忘 LoRA 的权重或作用位于这些方向”：还没有按 ΔW 响应能量分解，生成行为也是非线性的。

“纯文本也恢复，所以方向必然由视觉与文本共用”是合理假设，尚不是结论。替换后的模型可能通过注意力、MLP 与跨层传播影响纯文本；视觉来源二阶矩的方向也可能反映模型的通用表示。应分别报告纯文本提示文本 token、带图提示文本 token、视觉 token 的覆盖率，并补 §4.4 的 LoRA 响应比。仅有高覆盖率也不能证明是身份知识的因果方向。

C0 不是比 C1 更干净的隔离对照：C0 改 k 时也改变 down_proj 与视觉编码器的掩码；C1、C2 则将这些模块固定为 k=5/10。C0 是必须保留的算法基线，但三点近似共线只能说明已观测点的几何关系，不能证明中间真实曲线线性。λ10 相对 C0 的 +0.01431 应作描述性结果。

## 5. 夹点、强度与最终实测

加入 α=1.25 合理。建议采纳“夹点差超过 0.1 就二分，最多两次”的有上限补点机制，同时在补充协议中写清：

1. 只使用实际夹住目标的局部点，不外推；出现非单调或多个夹区间时，沿用冻结的插值口径，并提前指定最终强度的确定方式。
2. “离某个点 <0.02 就不补”只能是省算力的开发启发式。目标附近的保留曲线斜率可达约 0.73，0.02 的遗忘误差可对应约 0.015 的保留误差，超过 0.01 的判别阈值，不能保证比较精度。
3. 插值指标不等于某个插值强度的真实模型表现。插值确定 α 或 c 后，最终拟送确认的强度应至少在开发集实测一次，核对合并目标与文本 +5 点监控。若保留了未完全匹配的近邻点，应披露偏差，不能称为精确匹配。
4. 两次补点后仍无法可靠匹配，报告“预算内匹配不足”，不能据此判定算子被支配。

C3 达不到目标时依次补 α=5、8，作为预先设定的预算上限合理，但应报告为“τ=0.9、所测强度与当前预算下，未找到满足目标及文本约束的硬投影配置”，不要泛称硬投影无效。α 较大时须报告生成异常、回答长度及数值有限性；若软收缩也不满足约束，则不能因硬投影失败就宣布软收缩成功。

## 6. 提前诊断：可做，但要限定用途

用保存特征值检查 e_i/e₁ 阈值，建议采纳。本次 CPU 已复算 84 组：

| 阈值 | 全谱方向数 min / median / max | 实际保护 V_r 内方向数 min / median / max |
|---|---|---|
| >0.1 | 1 / 2 / 6 | 1 / 2 / 6 |
| >0.01 | 3 / 24 / 59 | 3 / 24 / 59 |
| >0.001 | 38 / 177.5 / 396 | 14 / 169 / 396 |

因为软收缩只对 V_r 生效，应以保护子空间内的计数解释。阈值 1/λ 对应被减去的系数 w>0.5，是“至少减半”的方向数，绝非“只有这些方向被收缩”；其余 V_r 内方向也受到连续收缩。最好同时报告按 ΔW 加权的响应能量。

S0d、S1 的确只需已有 B1 二阶矩，不需重新采 B1；但需分别做特征分解。D_fm、D_rh 尚需前向采集，可以提前做。按 v3，固定诊断人物/题目、层、token 分类后只做解释，不改变 λ、α、τ、模板或停止选择，否则就不再是纯诊断。S1 的“各占一半”是两种 token 平均矩阵各乘 1/2，并不自动意味着最终迹能量各占 50%。

3,852 文本 token 接近 3,584 维，提示估计可能不稳，但不是充分证据：token 强相关、模板重复且只来自 128 样本/44 人，有效样本量更小；同时前几大方向可能稳定。将来应按人物/样本拆分或重抽 B1，检查子空间覆盖率、主角和响应稳定性，不能只凭 token/维度比断言 C4 失败是噪声，也不能据零收益断言平衡普遍无用。

## 7. 外观留出题与第二折

只在 F1 上用 Original、SMFA、MFA 做灵敏度检查，值得采纳。每个模型 25×6=150 题，约几分钟，三模型总成本与加载开销另计。原任务中 MFA 的 6.4% 拒答不应被直接当作新任务的期望拒答率；任务难度不同，“三模型分不开”不自动证明题目无效，也可能反映这些属性没有受损。

现模板确有类别单一和一致度天花板风险，须同时看原始模型回答多样性、拒答率、模型间差值、人物区间及 ROUGE 对措辞变化的敏感性。Original 只是参照，不是真值。不要专门挑最能把 MFA 与 Original 拉开的题。

模板已在 A 阶段冻结，若要更换，须作为可追踪的协议修订，事先写定诊断标准、备选模板和最多一次替换，保留旧模板诊断；新模板再次查语义重叠，再在 C5/C6 结果出现之前锁定。仅看 F1，不动 F2。任务属性相近本身不等同于答案泄漏；这里遵守已有的严格任务留出约定，是为了限定辅助诊断的解释范围。

沿用 m=2.0、相同夹点与模板规则到第二折合理，不再根据 F2 表现重新定余量。不过不能说“h 只涉及方差而不涉及候选表现”：h 来自特定候选的逐人差值，依赖候选和人群；它只是未按均值收益挑选的规划量。需要披露 m 来自 F1，且未来作为第二折确认组的 F1 曾用于该全局设计。

第一折所有选择锁定后再进入第二折有助于防止串用结果；并不必须等第一折确认分数已揭晓。更稳妥是两折规则现在固定、第二折机械执行，不依据第一折确认结果作人工修改。若仍按“先出第一折确认结果、再第二折”执行，应披露 F2 已作为第一折确认集出现，不能称为完全盲的独立重复。

两折选择不同配置时，合并评价的是选择流程，不是固定模型。保留测试集两折共用同一批 200 人，不能算成 400 个独立人物；分折报告并以共同人物为簇处理重复测量。普通合并 bootstrap 不涵盖选择不确定性。

## 8. “七成/九成通过率”不宜作为已验证结论

若额外假设正态、真实事实性改善恰为 1.2 点、h=4.3015 可代表最终候选的 90% 半宽、50 人标准误恰按 √2 缩小，则 SE≈4.3015/1.64485=2.615。合并记忆单门槛的近似功效为 Φ((5+1.2)/SE−1.64485)：25 人约 76.6%，50 人约 95.6%。所以原文作为粗略量级判断并非完全离谱，但它不是可引用的实测通过率。

真实改善未知，ROUGE 到事实性换算未知，所选候选的方差未知，两折配置可能不同，单通道护栏及保留显著性也尚未计算。这些都使该估计不能保证整个实验有相应成功概率。默认两折的依据应继续是既有精度规划与冻结方案，而不是这一组乐观假设。

## 建议决策

先接受 C1 四点补测和原规则重选 λ；把有上限的夹点、最终开发实测、C3 强度上限、第二折固定 m 以及辅助模板修订机制写成独立补充协议，在新增候选结果出现之前锁定。保持 δ=5、单通道上限10、文本监控+5、0.01开发阈值及原冻结证据不变。诊断提前做可以，但不据其结果临时修改选择流程。新增实验尚未启动。
